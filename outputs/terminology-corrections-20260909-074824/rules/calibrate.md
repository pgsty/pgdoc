# PG 18.3 中文文档翻译校准表

本表用于组织 `doc/zh-18.3` 下全部 SGML 文档的多轮翻译工作。当前基线假设为“粗翻”，因此初始评分统一设为 `30` 分，共计 `389` 个 SGML 文件。

## 评分原则

1. 最终目标以 `100` 分为满分，要求译文专业、流畅、通顺。
2. 通常经过三轮翻译后，整体质量应达到 `90` 分以上。
3. 当前阶段为基线盘点，所有文件状态统一标记为 `粗翻`，评分统一为 `30`。
