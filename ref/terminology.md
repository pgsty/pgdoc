# 任务流程：术语校准（词表定稿后跨版本统一正文）

术语表（`docs/glossary.tsv` + `glossary.rules.tsv`，配套使用）定稿后，把各版本正文中仍用旧译/不一致同义表达的位置统一为定稿译法。此任务**不依赖英文最近有无改动**——"只处理英文 diff"的限制不适用；但一致性按技术概念判断，不为中文逐字相同而抹平版本差异。

## 判断顺序（每个候选位置）

1. **先确定技术含义和版本**：找到该中文段落对应版本的英文，确认对象、词性、领域、句法。
2. **先保护字面形式**：SQL、代码、名称、标识符、原始输出按 `exclude.tsv` 与译风保留；词表给出中文释义也不能翻译这些字面形式。区分大小写与 token 边界，优先长词组（`CC`≠`cc`，`JOIN`≠普通 join）。
3. **按逐条规则选用现用译名**：`glossary.rules.tsv` 是词表的必要解释，不是可选附件。
4. **按译风做最小语法调整**：允许调整紧邻助词/词序，不重写整段。

## 流程

### 1. 安装词表

改动前备份中文目标文件和 `docs/` 规则。安装时做三方比对：现用词表 == 最初原表 → 直接采用定稿；已 == 定稿 → 不重复改；后来人工新增条目 → 保留；冲突 → 逐项核实。规则与词表数量保持配套；变更登记到 `docs/change.md`。`en/`、`tmp/`、`outputs/` 被 git 忽略，须另存安装前后哈希，不能只凭 git diff 认定生效。

### 2. 按词族×版本矩阵组织

- 以词族（同族词条+简称+变体）为单位，每个词族覆盖全部适用版本；**不按版本各自独立定译法**。
- 双向检索：旧中文、旧英文词头、批准别名、常见变体；考虑大小写、词形、换行、内嵌 SGML 标签和实体。高歧义中文词（"主"、"结构"）从英文反向定位，不据中文字符串直接替换。
- 两层台账：词条×版本覆盖矩阵 + 每个概念位置的跨版本语义台账（词条 ID、文件与稳定锚点、该版英文证据、修改前后、各版处置、核查结果）。

### 3. 试点后按词族迁移

先小规模试点验证定位、代码保护、跨版本同步与台账流程，通过后逐词族闭合。每次只编辑已核实区间；脚本只能辅助已确定的修改，应用前检查原文本仍匹配；产生 diff 逐项审阅。每完成一个词族即闭合全部适用版本对应位置。

### 4. 全量审计（不抽样）

1. 旧译残留：每处应改项完成校准，每处保留项有明确理由。
2. 新译误用：新词是否误入代码、输出、异义语境、不适用版本。
3. 英文驱动漏项：未知旧译、简称、跨行/跨标签导致的中文漏检。
4. 跨版本覆盖：每个语义位置各版均有处置。
5. 结构保护：对照基线核对 SGML、ID、linkend、实体、注释；`git diff --check` 区分原有与新增问题。

### 5. 构建验收

对全部适用版本实际构建 HTML + A4/US PDF（顶层批量入口若缺该版本须显式加入），记录命令、退出码、产物；抽查相关代表页面。

## 豁免分类（每个候选必须有明确处置）

| 类别 | 含义 |
|---|---|
| `PROTECTED_LITERAL` | 代码、名称、输出等原样保留 |
| `DIFFERENT_SENSE` | 字面相同但不是该词条的技术含义 |
| `ACCEPTED_VARIANT` | 定稿允许的缩写/语法形式/简称；正在校准的同义正文不能借别名混用旧主译 |
| `VERSION_ABSENT_VERIFIED` | 该版英文确无此概念（须查过章节移动/改名/拆分/同义表达；零字面命中不成立） |
| `HISTORICAL_QUOTE` | 必须忠实的原始输出/引用/名称；发布说明普通叙述不因此整篇豁免 |
| `ORPHAN_NOT_INCLUDED` | 实测不在书籍包含链且英文快照无此文件 |
| `BLOCKED_EVIDENCE` | 找不到可靠英文对应/含义冲突——是未决项不是通过项 |

豁免至少给出词条 ID、版本、文件与稳定定位、中文片段、英文证据、理由；"历史用法""未找到""更自然"不构成证据。

## 语境边界判例（高发词条）

- **streaming replication** 仍为流复制；不把所有"流复制"改成流式传输。**master** 仅复制角色译主库；master key 是主密钥，不对单字"主"全局替换。
- **struct/structure**：C 的 struct 用结构体，一般数据结构保留"结构"。**transition function**：聚合状态语境用状态转移函数；类型转换函数、触发器过渡表不连带。
- **trigram**：pg_trgm 字符级对象为三字符组；tuple/词级 NLP 语境不套用。**skew**：分布不均为倾斜，统计不对称为偏度，clock/read/write skew 按完整词组。
- **B-tree**：说明性正文概念译 B-树；`btree` 访问方法名、`USING btree`、`btree_gist` 等标识符原样。**HOT** 主译堆内元组，不改成仅堆元组。
- **unlogged**：限定普通数据变更不记录 WAL，不推导为不产生任何日志；`UNLOGGED` 不译。
- **词头勘误 ≠ 代码替换**：`pg_checksum`→`pd_checksum` 类勘误只改词表与检索；正文代码、引用拼写忠于本版原文。
- **first-committer-win / first-updater-win**：wins 形式仅是检索别名；文献与代码实际拼写保留。
- **名称缩写类词条**（`cid`、`MVCC`、`pg_lsn`）：保留实际名称，规范的是中文释义；不把每个"日志序列号"补成"日志序列号类型"。
- 别名表只帮助定位与消歧，不能作为批量替换字典或继续混用旧主译的理由。

## 交付

各版实际校准后的正文、启用的词表与规则、可审阅 diff、按词条×版本统计的修改数、跨版本位置台账、豁免清单、未决项、构建验收结果。跨版本一致性 = 同一技术概念同一译名，不是整段中文逐字相同。
